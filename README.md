# НИОКР Команда — PWA для исполнителей работ (с Supabase-синхронизацией)

PWA-приложение для оперативного общения и обмена информацией между исполнителями НИОКР.
Устанавливается на рабочий стол смартфона: Android (Chrome) и iPhone (Safari).
Синхронизация сообщений, задач, объявлений и документов — в реальном времени через Supabase.

## Возможности
- **Чат по каналам** (Общий / Технические вопросы / Отчётность) с фото и файлами — реальное время
- **Задачи** — статусы, ответственные, сроки; изменения видны всем мгновенно
- **Объявления** — общая информационная лента
- **Файлы** — общее хранилище документов (Supabase Storage)
- **Офлайн** — приложение открывается без сети (Service Worker); данные загружаются при появлении сети

## Подключение Supabase (5 минут, бесплатно)

1. Зайдите на https://supabase.com → Start your project → создайте новый проект (регион: ближайший).
2. Откройте **SQL Editor** → New query → вставьте весь текст из файла `schema.sql` проекта → **Run**.
   Это создаст таблицы (messages, tasks, announcements, documents), включит Realtime и Storage-бакет `files`.
3. Откройте **Settings → API** → скопируйте **Project URL** и **anon public key**.
4. В файле `supabase-config.js` проекта замените:
   - `https://YOUR_PROJECT.supabase.co` → ваш Project URL
   - `YOUR_ANON_KEY` → ваш anon key
5. Закоммитьте и запушьте — синхронизация включится автоматически (в шапке появится бейдж «Синхронизация»).

⚠️ Если `supabase-config.js` не заполнен — приложение работает в локальном режиме (данные на устройстве).

## Примечания по безопасности
- Анонимный ключ (anon) безопасен для встраивания в клиентский код, но в схеме выше доступ открыт
  любому, у кого есть ссылка (политики RLS `for all to anon`). Для рабочего контура с
  конфиденциальными данными НИОКР рекомендуется: включить авторизацию (Supabase Auth,
  e-mail magic link) и заменить политики на `auth.uid() is not null`, либо развернуть
  self-hosted Supabase в корпоративной инфраструктуре.
- Размер загружаемых файлов разумно ограничить (Storage policies), бесплатный тариф Supabase: 1 ГБ.

## Структура
```
index.html            — приложение (UI + логика + слой синхронизации)
supabase-config.js    — URL и ключ вашего проекта Supabase
schema.sql            — SQL-схема: таблицы, RLS, Realtime, Storage
sw.js                 — Service Worker (офлайн-кэш)
manifest.webmanifest  — манифест PWA
icon-192.png, icon-512.png — иконки
```
