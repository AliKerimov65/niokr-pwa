# НИОКР Команда — PWA для исполнителей работ

PWA-приложение для оперативного общения и обмена информацией между исполнителями НИОКР.
Устанавливается на рабочий стол смартфона: Android (Chrome) и iPhone (Safari).

## Возможности
- **Чат** по каналам (Общий / Технические вопросы / Отчётность) с прикреплением фото и файлов
- **Задачи** — постановка, статусы (Новая / В работе / Выполнено), ответственные и сроки
- **Объявления** — информационная лента проекта
- **Файлы** — локальное хранилище документов с предпросмотром изображений
- **Офлайн-режим** — Service Worker кэширует приложение, работает без сети
- **Установка на рабочий стол** — нативная установка Android через prompt, на iOS — «На экран Домой»

## Быстрый старт (публикация)

1. Создайте репозиторий на GitHub и загрузите все файлы проекта.
2. Settings → Pages → Source: main branch → Save.
3. Через 1–2 минуты приложение доступно по адресу `https://<user>.github.io/<repo>/`.

HTTPS обязателен — без него PWA не устанавливается и Service Worker не работает.
Любой другой хостинг с HTTPS подойдёт (Netlify, Vercel, корпоративный сервер).

## Установка на смартфоны

**Android (Chrome):**
1. Откройте ссылку в Chrome → появится кнопка «Установить» / «Добавить на главный экран».
2. Либо: меню (⋮) → «Установить приложение» / «Добавить на главный экран».

**iPhone (Safari):**
1. Откройте ссылку в Safari.
2. «Поделиться» (квадрат со стрелкой) → «На экран "Домой"» → «Добавить».

## ⚠️ Важно: синхронизация между пользователями

Текущая версия — **local-first демо**: данные хранятся в localStorage конкретного устройства
и НЕ синхронизируются между исполнителями. Для реального обмена сообщениями подключите backend:

**Вариант 1 — Supabase (рекомендуется, ~15 строк кода):**
- Создайте проект на supabase.com (бесплатный тариф)
- Создайте таблицы: `messages (channel, author, role, text, created_at)`, `tasks`, `announcements`
- Включите Realtime для таблиц
- В `index.html` замените `store.get/set` на запросы к Supabase Realtime (подписка на INSERT)

**Вариант 2 — Firebase Realtime Database / Firestore:** аналогично, слушатель `onSnapshot`.

**Вариант 3 — корпоративный сервер:** WebSocket (Socket.IO) или готовые решения
(Mattermost/Rocket.Chat — если нужен полноценный корпоративный мессенджер с контролем доступа).

Для НИОКР с чувствительными данными рекомендуется Вариант 3 или self-hosted Supabase —
данные не покидают вашу инфраструктуру.

```
icon-192.png, icon-512.png — иконки
```
