# Инструкция: как создать новую команду (пошагово)

Приложение: https://alikerimov65.github.io/niokr-pwa/

## 1. Подготовка
Откройте приложение в браузере смартфона (Chrome — Android, Safari — iPhone) или на компьютере.
Рекомендуется установить на рабочий стол:
- **Android (Chrome):** меню «⋮» → «Установить приложение»
- **iPhone (Safari):** «Поделиться» → «На экран "Домой"» → «Добавить»

## 2. Выбор участника
1. При запуске откроется окно **«Кто вы?»**.
2. Выберите себя из выпадающего списка зарегистрированных участников → **«Это я»**.
   ⚠ **Важно:** написание имени должно совпадать посимвольно («Иванов И.И.» ≠ «Иванов И.И») —
   команды привязаны к имени, иначе команда «не видна».
3. Если вас нет в списке — «Зарегистрироваться»: фамилия и инициалы, роль, при желании телефон/e-mail/Telegram.

## 3. Создание команды
4. Откроется экран **«Выбор команды»**.
5. В блоке «Создать свою команду» введите название (например, «НИОКР Команда») → **«Создать»**.
6. Готово: вы — владелец, команда создана **чистой** (пустые чат, задачи, объявления, файлы, этапы).

## 4. Возможности владельца
- **🧩** в шапке — конструктор собственных вкладок (текст, ссылка, чек-лист, лента)
- **🔑 Код приглашения** — 6 символов, виден только владельцу (вкладка «Разное» / панель 👥)
- **👥** — управление составом: добавление/исключение, создание участников, правка карточек,
  перемещение между своими командами, удаление команды

## 5. Приглашение участников
**Способ 1 — по коду:** передайте код участнику → он: выбор себя → «Вступить по коду» → ввод → «Вступить».
**Способ 2 — владельцем:** «Разное» → «Состав команды» → выбор из списка → «+ В команду»
(или «＋ Создать нового участника»).

## 6. Переключение между командами
👥 в шапке → выбор команды. Данные команд изолированы, история не переносится.

## 7. Проблемы
- «Не вижу команду» — зашли под другим написанием имени → «👤 Сменить участника» в «Разное».
- «Нет новых функций» — полностью закройте и откройте приложение (автообновление при запуске).
- «Не отправляется» — проверьте интернет; в локальном режиме (бейдж «Локально») данные хранятся на устройстве.
